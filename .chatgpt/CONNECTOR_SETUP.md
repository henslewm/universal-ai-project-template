# ChatGPT Connector Setup

## Default

- GitHub: connect the canonical repository.
- Web search: use for current public facts and primary sources.

## Add only when relevant

- Google Drive: source documents and folders.
- Gmail: communications, evidence, and open loops.
- Google Calendar: deadlines, hearings, meetings, and availability.
- Google Contacts: person and recipient resolution.
- Legal/scientific/technical database: controlling domain authority.

## Permission posture

Start read-only. A connector's availability is not permission to send, delete, purchase, file, publish, change sharing, or modify records. Consequential writes require an explicit request in the current task.
