# History and Handoff Model

## What Git history should contain

- Changes to the project charter and instructions.
- Verified state transitions.
- Decisions and their rationale.
- Source-index additions or corrections.
- Drafts and outputs worth preserving.
- Scripts, tests, and validation changes.

## What chat history should contain

- Exploration, dialogue, and temporary reasoning.
- Questions and answers not yet promoted to durable state.
- Tool outputs that are too transient or voluminous for the repo.

## Handoff minimum

`HANDOFF_CURRENT.md` must state:

- active objective;
- branch/commit actually verified;
- what changed;
- sources relied upon;
- unresolved risks or contradictions;
- exact next action;
- actions that must not be assumed completed.
