# Connector and Skill Selection

## Connectors

Select a connector only when a deliverable depends on data that is more authoritative, current, or complete in that system than in the repository.

- GitHub: durable project state.
- Drive: authoritative documents/folders.
- Gmail: communications/evidence/open loops.
- Calendar: deadlines/hearings/meetings/availability.
- Contacts: identity/recipient resolution.
- Web: current public facts and official documentation.
- Specialist database: controlling legal/scientific/technical authority.

Default to read-only. Consequential writes require explicit current authority.

## Skills

Use an existing trusted skill when it fits. Create a custom skill when the workflow repeats, has concrete inputs/outputs, benefits from scripts/validation, or requires project-specific conventions. Do not create skills for one-off answers or generic knowledge.
