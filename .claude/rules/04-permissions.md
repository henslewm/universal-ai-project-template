# Permissions

Connector or tool availability is not authority for a consequential action. Read-only is the default. Require explicit user direction before sending communications, publishing, filing, purchasing, deleting, changing permissions, or modifying external records. The automatic closeout commands (push, ready-merge with branch cleanup, issue mirroring; `MASTER_INSTRUCTIONS.md` → "Automatic closeout (ADR-094)") are standing owner direction and need no further prompt. Launching a metered (paid) model through `scripts/worker_launcher.py` within the per-packet budget and attempt limits needs no further prompt only where `DECISIONS.md` records that owner direction; raising either limit always needs the owner.
