Libraries accept Markdown, code, PDF, and Office files (up to 100 files per upload, 100 MB per file). Re-upload changed control files after material repository updates, or rely on the GitHub connector so chats never read stale copies. Do not rely on chat-to-chat continuity or Memories: if it matters, it belongs in the repository.
